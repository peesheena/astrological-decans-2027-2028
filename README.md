# Astrological Decans 2027–2028

This repository contains an iCalendar file for the 36 tropical-zodiac decans from 21 March 2027 through 20 March 2028.

- **Calendar:** `astrological-decans-2027-2028.ics`
- **Timezone:** AEST (UTC+10)
- **Event style:** `Aries I`, `Aries II`, `Aries III`, and so forth
- **Event times:** Timed transitions based on the supplied tropical zodiac table

Import the `.ics` file into Apple Calendar, Google Calendar, Outlook, or another iCalendar-compatible application.
